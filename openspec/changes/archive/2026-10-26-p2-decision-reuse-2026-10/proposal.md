# P2：一次对话只问一次模型

## 为什么改

对话入口在规则读不懂时问一次模型，写意图随后进入 `TaskRuntime._run`，
台账又用同一份请求重新 `brain.plan` 一次。实测一段退款对话 **2 次调用 /
918+645 token / 20.3 秒**（ADR-020）。「台账不信任入口」是安全属性，
不能为了省一次调用删掉；问题在于用「重算」代替了「复核」。

## 改什么

1. 入口把模型结论写成**可复核的决策记录**：请求与上下文摘要、规则指纹、
   模型名、入口当次的规则读数、模型读数与用量。
2. 台账收到记录后**独立复核**（摘要、规则指纹、模型名、规则读数逐项一致），
   一致才复用；任何一项不一致就回到原来的重算路径（最坏多问一次）。
3. 复用不伪造台账：`task.routed.planning_source` 仍由台账写入，
   记录里新增 `model_reused=true`，`llm_usage` 不再落第二行。
4. `AGENT_MODE=rules` 仍为 0 次调用；入口没有模型结论时不传记录。

## 不做

- 不把模型结论写进任务请求字段（那等于让入口控制台账）。
- 不因复用而跳过资格校验、审批与写路径。
- 不在本轮改变「入口只采纳退款」的范围。
