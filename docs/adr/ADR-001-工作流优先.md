# ADR-001：确定性 Workflow 优先，Agent 只做有界节点

- 状态：Accepted
- 日期：2026-10-23

## 背景

售后任务同时包含语言不确定性和严格业务规则。若把订单查询、资格判断、审批和退款执行全部交给自主 Agent，会出现不可复现、难审计、成本不可控、越权风险高的问题。

## 决策

任务控制流由 `TaskRuntime` 确定性实现：

1. 规则优先分类意图
2. 固定节点执行固定工具
3. 写操作统一经过 Tool Gateway
4. 语言模型只在需要时补槽位或解释
5. 业务结论与最终成功由服务端规则和权威记录决定

## 后果

优点：

- 可测试、可回放、可审计
- 成本可预测（规则模式零模型调用）
- 失败路径明确，便于恢复
- 权限与业务规则不依赖模型服从性

代价：

- 灵活性低于开放式 Agent
- 新意图需要显式加规则/节点
- 复杂多步规划不在第一版能力内

## 备选方案

- 全自主 Agent + 工具：拒绝，风险与不可控成本
- 纯工作流、不用 LLM：拒绝，自然语言理解与解释能力不足
